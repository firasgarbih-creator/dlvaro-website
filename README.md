# موقع DLVARO

موقع تعريفي ثنائي اللغة (العربية والإنجليزية) لعلامة DLVARO، من دون متجر أو دفع إلكتروني.

## الملفات

- `index.html`: الصفحة الرئيسية ومدخل الأقسام الثلاثة.
- `products.html`: عرض DV-01 ومواصفاتها.
- `about.html`: من نحن ومبادئ هوية التأسيس كاملة بالعربية والإنجليزية.
- `identity.html`: الهوية البصرية المعتمدة وتوقيع المثلثات ثلاثية الأبعاد.
- `accessories.html`: السوار الحالي والاستفسار عن الأكسسوارات.
- `service.html`: استفسارات الضمان والصيانة دون شروط غير معتمدة.
- `dv-01.html`: صفحة تقديم ساعة DV-01 LIMITED EDITION.
- `account.html` و`account.js`: تسجيل العملاء برمز بريد من 8 أرقام وإدارة الاشتراك الاختياري بالأخبار.
- `data/account-config.json`: عنوان Supabase والمفتاح العام فقط؛ يمنع وضع أي مفتاح سري فيه.
- `styles.css`: التصميم المتجاوب.
- `app.js`: الترجمة والتفاعل.
- `data/watch.json`: بيانات الساعة ووصفها باللغتين.
- `assets/`: الشعار وصورة المنتج المعتمدة.
- `CNAME`: النطاق المخصص `www.dlvaroofficial.com`.
- `sitemap.xml` و`robots.txt`: إعدادات الفهرسة لمحركات البحث.
- `.nojekyll`: يسمح لـGitHub Pages بتقديم الملفات الثابتة كما هي.

## تحديث بيانات الساعة

افتحوا `data/watch.json` وعدّلوا القيمة المطلوبة مع إبقاء علامات الاقتباس والفواصل كما هي. يحتوي الملف على الاسم والموديل والحركة والعلبة والكريستال ومقاومة الماء والسوار والأبعاد وحالة التوفر، إضافة إلى الوصف العربي والإنجليزي. تظهر التعديلات تلقائيًا في صفحات المنتجات وتفاصيل الساعة عند نشر الملفات المحدّثة.

لتغيير نصوص الموقع العامة أو التسميات المترجمة، تُعدّل الترجمات في بداية `app.js`.

## النشر

الموقع مبني كملفات ثابتة على GitHub Pages، وتستخدم حسابات العملاء Supabase. انشروا ملفات HTML وCSS وJavaScript العامة ومجلدي `assets/` و`data/` وملفات `CNAME` و`.nojekyll` و`robots.txt` و`sitemap.xml` فقط. لا تنشروا `work/` أو `outputs/` أو ملفات الاعتماد. النطاق الحالي `www.dlvaroofficial.com`.

## حسابات العملاء

المشروع: `DLVAROOFFICIAL`، المرجع `ggpgvktcazqovbafadzn`. يتولى Supabase تأكيد البريد والجلسات؛ تخزن الجلسة في sessionStorage لهذا التبويب. النشرة اختيارية وغير محددة مسبقًا، ولا تُحفظ الموافقة إلا بعد تأكيد البريد. وظيفة `set_customer_preferences` تسجل الاشتراك وتغيراته، وسياسة RLS تسمح لكل مستخدم بقراءة تفضيلاته فقط. لا تُعرض عناوين العملاء عبر الجداول العامة.

المخطط المطبق محفوظ في `work/customer-accounts.sql`، وقالب الرسائل في `work/email-templates/sign-in.html`. لا تعيدوا تنفيذ إنشاء الجداول على مشروع قائم. البريد المرسل `social@dlvaroofficial.com` والاسم `DLVAROOFFICIAL`، عبر Resend SMTP. مفتاح الإرسال محفوظ في Supabase فقط. عند تدويره يلزم تحديث SMTP هناك، وليس ملفات الموقع.

ميزة الاشتراك تحفظ قائمة الموافقات؛ إرسال الحملات التسويقية غير مؤتمت. يجب احترام آخر تفضيل للعميل وإتاحة إلغاء الاشتراك عند إعداد أي حملة. طلب حذف الحساب يوجه لخدمة العملاء؛ حذف المستخدم من Supabase يحذف تفضيلاته وسجل موافقته بالتبعية.
